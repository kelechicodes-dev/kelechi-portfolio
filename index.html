02 Build log
first build
Kelechi Calculator
Converted a TypeScript/HTML calculator into a working Expo app. First taste of Metro, JSX, and mobile styling.
second build
HabitTracker
First app with real local persistence and interaction — streaks, long-press to rename, colored checkboxes. Pushed to GitHub via GitHub Desktop after Git CLI kept getting blocked by Windows Smart App Control.
third build
Kelechi Weather
Fought Quick Heal, Windows Firewall, and Smart App Control all night just to get a QR code to connect — then shipped geolocation, a 5-day forecast, and live weather animations.
fourth build
Truth or Dare
First web-based build instead of a mobile app — a flip-card party game with four categories and custom questions saved via localStorage.
fifth build
Kelechi Study Bud
A voice-first AI study assistant — Gemini API behind a free Cloudflare Worker, speech in and out, camera note scanning, quiz mode, and calm ambient sound.
sixth build
Pulse
A live poll website — Supabase handles auth-free realtime voting. Hit a config.js 404 and a 127.0.0.1-vs-real-IP snag testing cross-device, fixed both, shipped it.
